# Job Description: SQL & Power BI Contractor
**Company:** JDL Access, LLC
**Location:** Not specified (Contract)
**Type:** Contract
**Pay:** Not specified
**Posted/Applied:** 2026-07-24

## Overview
JDL Access, LLC is a medical technology patient and payer access firm seeking a contractor to build and structure reporting workflows within a SQL database environment and surface insights through Power BI dashboards. Works with developer and operations teams on a MongoDB-backed platform.

## Key Responsibilities
- Replicate complex business logic and reporting structures from relational SQL into Power BI dashboards
- Configure and optimize connections between MongoDB and Power BI (MongoDB BI Connector or CData drivers)
- Use Power Query (M language) to clean, flatten, and transform nested JSON-like MongoDB structures into tabular formats
- Create advanced DAX measures and calculated columns to meet KPI requirements
- Optimize SQL queries and Power BI data models for performance
- Design and write optimized SQL queries and stored procedures to extract, transform, and aggregate data
- Document data sources, query logic, and report definitions for long-term maintainability

## Required Qualifications
- Expert proficiency in Power BI Desktop, Power BI Service, and SQL (T-SQL, PostgreSQL, or similar)
- Proven experience connecting Power BI to MongoDB Atlas or on-premise instances
- Strong understanding of star schemas and relational vs. non-relational data structures
- Ability to document data lineage and transformation steps
