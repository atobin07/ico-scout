# EDI Technical Analyst — Confidential Employer

**Date Saved:** 2026-06-24
**Source:** Provided by user

## Job Summary
The EDI Technical Analyst develops technical documentation and designs, analyzes, tests, and supports applications and data structures used for electronic data interchange (EDI) and flat file processing. Provides end-user support and training, performs post-implementation reviews, and supports systems and reporting for internal customers across multiple responsibility levels.

## Key Responsibilities
- Track, research, analyze, and resolve production processing problems, coordinating with appropriate teams
- Develop business objectives, processing requirements, and technical specifications for EDI-related processes
- Analyze files and map data between systems to support EDI and flat file transactions
- Write and maintain SQL queries for production support, testing, and reporting
- Query logging and monitoring tools (Splunk or similar) to investigate issues
- Develop test data, create/process test files, and analyze test results
- Use API testing tools (SOAP UI, Postman) to validate integrations
- Execute test cases, document results, log defects, regression testing, root cause analysis
- Apply industry rules and guidelines (TR3, CAQH core rules) to EDI transactions
- Translate business needs into technical solutions (SQL, C#/VB.NET, ETL, SOA, OLAP)
- Build, support, and maintain processes, programs, and data integrations of increasing complexity
- Create dashboards to monitor transactions and performance indicators for EDI process health
- Lead or participate in projects including technical discovery and solution design
- Provide peer review, guidance, and mentoring to less experienced analysts

## Requirements
- Experience with EDI transactions and trading partner integrations
- Proficiency with EDI document types (eligibility, claims, remittance — healthcare context)
- SQL and relational database skills for analysis, testing, and reporting
- Data mapping, data analysis, and integration techniques across multiple systems
- API testing tools (SOAP UI, Postman) and basic API troubleshooting
- Logging/monitoring tools (Splunk or similar)
- Strong documentation skills for technical specs, process flows, test artifacts
- Previous experience with QNXT a plus
- Healthcare-related systems/transactions experience highly beneficial
