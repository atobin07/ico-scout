## Job Description

Amped Marketing is a full-service marketing and advertising agency building and managing websites for clients across many industries. Seeking a developer who builds fast by leveraging AI tools as the core of their workflow.

**What You'll Do:**
- Turn Figma designs into live, responsive websites using Figma's built-in dev tooling and AI code generation
- Clean up and refine AI-generated output to production quality
- Build and launch client sites on WordPress (mainly) and Shopify
- Work directly with design and account teams to move projects from concept to launch quickly
- Handle QA, cross-browser testing, and post-launch fixes
- Keep an eye on new AI dev tools and bring useful ones into the process

**What They're Looking For:**
- Real experience shipping websites, ideally in an agency or high-volume environment
- Fluency with Figma, especially Dev Mode and code generation features
- Daily use of AI coding tools like Claude Code, Cursor, Copilot, or v0
- Strong HTML, CSS, and JavaScript fundamentals (need to know when AI got it wrong)
- Attention to detail: page speed, semantic markup, accessibility, mobile behavior
- Comfort juggling several client projects with real deadlines

**Nice to Have:**
- SEO-friendly development practices
- Experience with Webflow, Framer, or similar
- Basic understanding of how AI search and answer engines read a site

**Application Question:**
- Describe a website you built recently and which AI tools you used at each stage
