# Job Description: Data & AI Platform Architect
**Company:** Confidential (Commercial Real Estate, San Diego CA)
**Location:** San Diego, CA — Hybrid
**Type:** Direct Hire / Permanent
**Compensation:** $150–180k + 10% bonus
**Posted/Applied:** 2026-06-30

## Overview
Highly capable data engineering and architecture professional with forward-looking AI mindset. Responsible for designing and owning a modern data and AI ecosystem supporting commercial property data. Driving force behind conversational data initiative enabling natural language data interaction.

## Core Areas
- **Data Platform & Integration (35–45%):** Microsoft Fabric/OneLake, lakehouse structures, Delta tables, Dataflow Gen2, DirectLake models; ingestion from Yardi, SharePoint, CoStar, GreenStreet, Argus, etc.
- **AI Enablement & Automation (35–45%):** Azure AI, Copilot, conversational AI assistants in Teams/Outlook, vector-based search, RAG, Power Automate workflows
- **Security & Data Governance (ongoing):** Access management, query-level security, auditability, compliance
- **BI Collaboration (10–20%):** Partner with BI teams, support dashboard migration to cloud-native

## Technical Requirements
- Microsoft Fabric / OneLake — lakehouse, pipeline orchestration, Delta tables, semantic modeling
- SQL — advanced querying across database types
- Python — data processing, automation, API interaction
- Azure AI — Azure OpenAI, AI Search, Copilot tooling, RAG, vector indexing
- Power BI — reporting, modeling, admin
- Power Automate — workflow orchestration
- REST APIs & custom connectors
- Git-based source control

## Experience Required
- Bachelor's in CS, Information Systems, Analytics, or related
- Several years in data engineering, analytics engineering, or platform BI roles
- Production-grade pipeline builds in Fabric, Azure Data Lake, Databricks, or similar
- AI-driven solutions using LLMs beyond simple prompting (RAG, vector indexing, API integrations)
- Real estate or finance exposure helpful but not required
