# Job Description: Shopify Web Developer
**Company:** World Pantry
**Location:** Not specified
**Type:** Full-time
**Posted/Applied:** 2026-07-27

## Overview
Shopify Web Developer on the Engineering Team to create, customize, and maintain design, functionality, and UI/UX of multiple webstore properties. Implement and modify A/B tests to improve customer engagement and conversion rates. Part of a turn-key branded webstore solution for direct-to-consumer brand partners.

## Key Responsibilities
- Develop, test, and deploy responsive websites using HTML, CSS, JavaScript, Angular, React, Bootstrap
- Collaborate with UX/UI designers to translate wireframes into functional interfaces
- Build and maintain back-end systems with Django, Spring, Ruby on Rails, or ASP.NET; databases: MySQL, PostgreSQL, SQL Server, MongoDB
- Implement RESTful APIs and integrate third-party web services (SOAP, GraphQL)
- Manage version control with GitHub/SVN; participate in code reviews
- Set up CI/CD pipelines with Jenkins or Azure DevOps
- Utilize Docker, Ansible for DevOps workflows
- Cloud platforms: AWS or Azure
- Unit testing, debugging, performance optimization, data visualization
- Agile/Scrum with Trello or Jira

## Qualifications
- BS/MS in computer science or related field, or commensurate experience
- 5+ years of Shopify development experience
- Proficiency in HTML, CSS, JavaScript, jQuery, and Liquid template language
- In-depth knowledge of Shopify theme and app customization
- Experience with responsive design
- Major JavaScript framework experience (React, Angular)
- RESTful web services and API experience
- Adobe Creative Suite experience (Photoshop, Illustrator)
