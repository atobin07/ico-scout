# Job Description: Data Analyst (Oracle HCM Cloud)
**Company:** Confidential
**Location:** 100% Remote
**Type:** Multiyear Contract (C2C or W2)
**Pay:** Open
**Posted/Applied:** 2026-07-01

## Overview
Experienced contractor to support advanced data development and modernization within an HR analytics environment. Focus on complex SQL across SQL Server and Oracle, sourcing and transforming Oracle HCM data for enterprise reporting and analytics.

## Responsibilities
- Develop and maintain complex SQL and database objects across SQL Server and Oracle
- Support HR data replication and modernization; translate legacy SQL Server logic to Oracle HCM-sourced data
- Design data structures, transformations, and database objects for analytics and reporting
- Leverage Oracle Analytics tools (BI Publisher) to source, validate, and interpret Oracle HCM data
- Analyze Oracle HCM frontend functionality and backend data structures
- Partner with technical, analytics, and business stakeholders to define requirements and data logic
- Create and maintain technical documentation: data definitions, business rules, source-to-target mappings, data lineage, governance artifacts
- Contribute to data quality checks, reconciliations, and cross-system issue resolution

## Required Qualifications
- Advanced SQL — complex joins, analytical/window functions, performance optimization
- SQL Server AND Oracle SQL (both required)
- Strong Oracle HCM Cloud experience — frontend configuration and backend data structures
- Oracle Analytics tools: BI Publisher (BIP) and BICC
- Experience with legacy HR systems (e.g., PeopleSoft) modernization
- Enterprise data warehousing concepts (fact tables, historical data design)
- Clear, well-structured technical documentation for data governance
