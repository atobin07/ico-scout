# Job Description: Website & Systems Integration Administrator
**Company:** PrideStaff (on behalf of a premier local organization)
**Location:** 100% Remote
**Type:** Part-Time / Temporary
**Hours:** 10–40 hours/month (flexible, project-and-support based)
**Reports To:** Director of Sales, Marketing, and Development
**Posted/Applied:** 2026-07-27

## Overview
Primary architect and administrator of client's digital ecosystem — core website, event registration pipelines, CRM systems, and donor databases. Expert WordPress administrator who excels at system troubleshooting, API data mapping, and proactive platform maintenance.

## Key Responsibilities
1. **WordPress Core Administration** — site health, page layout design, performance optimization, plugin upkeep; audit, debug, and patch errors, broken links, plugin conflicts
2. **Event & Registration Systems** — manage EventOn or similar; resolve registration flow bottlenecks and ticketing logic issues
3. **Systems Integration, Automation & Data Mapping** — Zapier, custom webhooks, REST APIs; data integrity across Stripe, Constant Contact, Microsoft 365
4. **Database & CRM Migration Support** — FileMaker Pro data migration to Neon One donor management and Planning Pod CRMs
5. **Internal Technical Support** — go-to for leadership, Finance (Stripe revenue reporting), and Event Sales

## Required Qualifications
- WordPress Mastery: 2–4+ years hands-on WordPress admin, custom troubleshooting, site speed/security optimization
- Integrations & Automation: Zapier, webhooks, API data mapping across platforms
- Database & CRM familiarity: data structures, cross-platform syncing, CRM/donor databases (Neon One or Planning Pod a plus)
- Troubleshooting: rapid diagnosis of payment gateway glitches, webform drops, email sync failures
- High-availability SLA: 1-hour response for critical outages; 1 business day for routine tickets
- Non-profit/retreat center experience desirable
